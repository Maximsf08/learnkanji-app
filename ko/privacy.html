Learn Kanji: Pen-Enabled 개인정보 처리방침

마지막 업데이트: 2026년 11월 2일

Learn Kanji: Pen-Enabled는 Windows와 브라우저에서 쓸 수 있는 한자 쓰기 연습 앱이에요. 개인정보를 수집, 저장, 전송, 공유하지 않아요.

  • 쓴 내용, 진행 상황, 설정은 내 기기에서 앱 전용 데이터 폴더에만 저장돼요.
  • 앱에는 계정, 분석 도구, 광고, 추적이 없고, 레슨에 인터넷 연결이 필요하지 않아요.
  • 기초 1은 구매할 필요가 없어요. Learn Kanji Full(구독 또는 1회 구매)을 사면 Microsoft Store가 구매와 갱신을 처리하고, Microsoft 계정에 어떤 플랜이 있고 언제까지인지 앱에 알려 줘요. 앱은 결제 정보를 받지 않아요. 구독은 Microsoft 계정에서 관리하고 취소할 수 있어요. Microsoft Store에는 Microsoft의 개인정보 보호정책이 적용돼요: privacy.microsoft.com.
  • 스피커 버튼을 누르면 Windows가 기기에 설치된 음성으로 단어를 소리 내어 읽어 줘요.
  • 저장한 백업은 내 기기에 있는 파일이에요. 앱은 백업을 업로드하지 않아요.
  • 친구에게 보내는 초대 코드와 감사 코드는 내 기기에서 무작위 숫자로 만들어져요. 코드에는 개인정보가 없고, 앱은 코드를 어디로도 보내지 않아요. 원하면 직접 공유할 수 있어요.
  • 문제 해결을 위해 앱은 짧은 기술 로그(시작할 때의 메시지와 Store 메시지이며, 개인정보는 없어요)를 내 기기의 데이터 폴더에 보관해요. 이 로그는 어디로도 전송되지 않아요.

앱을 제거하면 앱이 저장한 모든 내용이 삭제돼요.

브라우저에서

Learn Kanji의 웹 에디션(learnkanji.app/app)도 같은 원칙을 따르고, 다른 점은 다음과 같아요:

  • 쓴 내용, 진행 상황, 설정은 내 기기에 있는 브라우저 저장소에만 저장돼요. 사이트 데이터를 지우거나 설치한 앱을 제거하면 함께 삭제돼요.
  • 브라우저에서 Learn Kanji Full을 구매하면 Gumroad가 결제와 갱신, 영수증을 처리하고, 여기에는 Gumroad의 개인정보 처리방침이 적용돼요: gumroad.com/privacy. 앱은 결제 정보를 전혀 받지 않아요.
  • 라이선스 키를 입력하면 앱이 키를 확인하려고 Gumroad의 라이선스 서비스로 보내고, 온라인일 때 가끔 다시 확인해요. 전송되는 것은 키와 그 키가 속한 제품뿐이고, 앱은 플랜과 그 날짜만 내 기기에 보관해요.
  • 스피커 버튼을 누르면 기기에 내장된 음성 기능이 단어를 소리 내어 읽어 줘요. 브라우저나 운영 체제가 제공하는 일부 음성은 온라인 서비스를 쓸 수 있는데, 앱은 그 데이터를 제어하지도 받지도 않아요.
  • maximsf08.github.io/learn-kanji에 있던 예전 웹 버전을 썼다면, 그 주소에서 같은 브라우저의 웹 에디션으로 진행 상황을 가져올 수 있어요. 진행 상황은 링크에서 “#” 뒤에 오는 부분에 담겨 전달되는데, 브라우저는 이 부분을 어떤 서버로도 보내지 않아요. 웹 에디션은 진행 상황을 가져오기 전에 먼저 물어봐요.
