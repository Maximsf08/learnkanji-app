นโยบายความเป็นส่วนตัวของ Learn Kanji: Pen-Enabled

ปรับปรุงล่าสุด: 2 พฤศจิกายน ค.ศ. 2026

Learn Kanji: Pen-Enabled เป็นแอปฝึกเขียนคันจิสำหรับ Windows และสำหรับเบราว์เซอร์ แอปไม่เก็บรวบรวม ไม่จัดเก็บ ไม่ส่ง และไม่แบ่งปันข้อมูลส่วนตัว

  • สิ่งที่เขียน ความคืบหน้า และการตั้งค่าจะถูกเก็บไว้ในอุปกรณ์ของคุณเท่านั้น ในโฟลเดอร์ข้อมูลของแอปเอง
  • แอปไม่มีบัญชีผู้ใช้ ระบบวิเคราะห์การใช้งาน โฆษณา หรือการติดตามผู้ใช้ และบทเรียนไม่ต้องใช้การเชื่อมต่ออินเทอร์เน็ต
  • พื้นฐาน 1 ไม่ต้องซื้อ หากซื้อ Learn Kanji Full (แบบสมัครสมาชิกหรือซื้อครั้งเดียว) Microsoft Store จะดูแลการซื้อและการต่ออายุ (ถ้ามี) และแจ้งแอปว่าบัญชี Microsoft มีแพ็กเกจใดและมีผลถึงเมื่อใด แอปไม่ได้รับรายละเอียดการชำระเงิน จัดการและยกเลิกการสมัครสมาชิกได้ในบัญชี Microsoft คำชี้แจงเกี่ยวกับความเป็นส่วนตัวของ Microsoft ใช้กับ Microsoft Store: privacy.microsoft.com
  • เมื่อแตะปุ่มลำโพง Windows จะอ่านคำออกเสียงด้วยเสียงที่ติดตั้งไว้ในอุปกรณ์ของคุณ
  • ข้อมูลสำรองที่บันทึกไว้เป็นไฟล์บนอุปกรณ์ของคุณเอง แอปไม่อัปโหลดไฟล์เหล่านั้น
  • รหัสเชิญและรหัสขอบคุณสำหรับเพื่อนสร้างขึ้นบนอุปกรณ์ของคุณจากตัวเลขสุ่ม รหัสเหล่านี้ไม่มีข้อมูลส่วนตัว และแอปไม่เคยส่งรหัสไปที่ใดเลย หากต้องการ ผู้ใช้แชร์เองได้
  • เพื่อการแก้ไขปัญหา แอปเก็บบันทึกทางเทคนิคสั้นๆ (ข้อความตอนเริ่มทำงานและข้อความจาก Store ไม่มีข้อมูลส่วนตัว) ไว้ในโฟลเดอร์ข้อมูลของแอปบนอุปกรณ์ของคุณ บันทึกนี้ไม่เคยถูกส่งไปที่ใดเลย

การถอนการติดตั้งแอปจะลบทุกสิ่งที่แอปเก็บไว้

ในเบราว์เซอร์

เวอร์ชันเว็บของ Learn Kanji (learnkanji.app/app) เป็นไปตามกฎเดียวกัน โดยมีข้อแตกต่างต่อไปนี้:

  • สิ่งที่เขียน ความคืบหน้า และการตั้งค่าจะถูกเก็บไว้ในที่เก็บข้อมูลของเบราว์เซอร์บนอุปกรณ์ของคุณเท่านั้น การล้างข้อมูลของเว็บไซต์ หรือการลบแอปที่ติดตั้งไว้ จะลบข้อมูลเหล่านี้ไปด้วย
  • หากซื้อ Learn Kanji Full ในเวอร์ชันเว็บ Gumroad จะดูแลการชำระเงิน การต่ออายุ (ถ้ามี) และใบเสร็จ และนโยบายความเป็นส่วนตัวของ Gumroad ใช้กับเรื่องนั้น: gumroad.com/privacy แอปไม่เคยได้รับรายละเอียดการชำระเงิน
  • เมื่อใส่คีย์ใบอนุญาต แอปจะส่งคีย์ไปยังบริการใบอนุญาตของ Gumroad เพื่อตรวจสอบ และตรวจสอบซ้ำเป็นครั้งคราวขณะที่ออนไลน์ โดยส่งเฉพาะคีย์และผลิตภัณฑ์ที่คีย์นั้นเป็นของ ส่วนแอปจะเก็บเฉพาะแพ็กเกจและวันที่ของแพ็กเกจนั้นไว้ในอุปกรณ์ของคุณ
  • เมื่อแตะปุ่มลำโพง ฟีเจอร์เสียงพูดที่มีในตัวอุปกรณ์จะอ่านคำออกเสียง เสียงบางเสียงที่เบราว์เซอร์หรือระบบปฏิบัติการจัดหาให้อาจใช้บริการออนไลน์ แอปไม่ได้ควบคุมและไม่ได้รับข้อมูลนั้น
  • หากเคยใช้เวอร์ชันเว็บรุ่นก่อนหน้าบน maximsf08.github.io/learn-kanji ที่อยู่นั้นสามารถนำความคืบหน้ามายังเวอร์ชันเว็บในเบราว์เซอร์เดียวกันได้ โดยส่งความคืบหน้าผ่านส่วนของลิงก์ที่อยู่หลัง “#” ซึ่งเบราว์เซอร์ไม่ส่งไปยังเซิร์ฟเวอร์ใดเลย และเวอร์ชันเว็บจะถามก่อนนำความคืบหน้านั้นเข้ามา
