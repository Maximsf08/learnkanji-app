Learn Kanji: Pen-Enabled 隱私權政策

最後更新：2026 年 11 月 2 日

Learn Kanji: Pen-Enabled 是一款漢字書寫練習應用程式，適用於 Windows 和你的瀏覽器。它不會收集、儲存、傳輸或分享個人資料。

  • 你寫下的內容、進度和設定只儲存在你的裝置上，位於應用程式專屬的資料夾中。
  • 應用程式沒有帳戶、數據分析、廣告或追蹤，而且它的課程不需要網路連線。
  • 基礎1不需要購買。如果你購買 Learn Kanji Full（訂閱或一次性購買），Microsoft Store 會處理購買和所有續訂，並告訴應用程式你的 Microsoft 帳戶有哪個方案，以及到何時為止。應用程式不會收到你的付款資料。你在 Microsoft 帳戶中管理和取消訂閱。Microsoft 的隱私權聲明適用於 Microsoft Store：privacy.microsoft.com。
  • 當你點一下喇叭按鈕時，Windows 會用你裝置上安裝的語音朗讀該詞語。
  • 你儲存的備份是你自己裝置上的檔案。應用程式不會上傳它們。
  • 給朋友的邀請碼和感謝碼，是在你的裝置上用隨機數字產生的。它們不含任何個人資料，應用程式也絕不會把它們傳送到任何地方：想分享的話，由你自己來分享。
  • 為了疑難排解，應用程式會在你裝置上專屬於它的資料夾中，保留一份簡短的技術記錄檔（啟動訊息和 Microsoft Store 訊息，不含個人資料）。這份記錄檔絕不會被傳送到任何地方。

解除安裝應用程式後，它儲存的所有內容都會被移除。

在你的瀏覽器中

Learn Kanji 的網頁版（learnkanji.app/app）遵循相同的規則，但有以下差異：

  • 你寫下的內容、進度和設定只儲存在你裝置上瀏覽器的儲存空間中。清除網站資料，或移除已安裝的應用程式，就會一併移除這些內容。
  • 如果你在網頁版購買 Learn Kanji Full，Gumroad 會處理付款、所有續訂和你的收據，而 Gumroad 的隱私權政策適用於這些：gumroad.com/privacy。應用程式絕不會收到你的付款資料。
  • 當你輸入授權金鑰時，應用程式會把金鑰傳送給 Gumroad 的授權服務來確認，並在你連線時不定期再次確認。只會傳送金鑰和它所屬的產品；應用程式只在你的裝置上保留方案及其日期。
  • 當你點一下喇叭按鈕時，你裝置內建的語音功能會朗讀該詞語。瀏覽器或作業系統提供的某些語音可能會使用線上服務；應用程式不會控制或接收該資料。
  • 如果你用過位於 maximsf08.github.io/learn-kanji 的先前網頁版，那個網址可以在同一個瀏覽器中，把你的進度帶到網頁版。它把進度放在連結中「#」之後的部分來傳遞，瀏覽器不會把這部分傳送給任何伺服器，而且網頁版在匯入之前會先詢問你。
