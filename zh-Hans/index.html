使用方式

看、描、凭记忆写

和日本孩子学汉字的方式一样，还有一位耐心的老师逐笔检查。

逐笔检查

你写的时候，会检查笔顺、方向和形状；写完后，红笔标记会为每个汉字打分，从花丸到三角形。

全部日本常用汉字

六个级别共 2,141 个汉字，每个只教一次：全部 2,136 个日本常用汉字，另加中级教材里的 5 个。基础级别和中级级别的课序与 Basic Kanji Book 和 Intermediate Kanji Book 一致，方便你跟上班级的进度。

记得牢的复习

每个汉字都会在你快要忘记它之前回来：刚学时回来得很勤，等你记住了，就越来越少。

为 JLPT 做好准备

选择 N5 到 N1 中的一个 JLPT 级别，或你的课程级别，一切都会以它为准。练习考试里的两类汉字题，还有限时测试。

无需会假名

每个读音也会用罗马音显示，所以你在还不会读平假名和片假名时就能开始。等你准备好了，再把它关掉。

离线且私密

没有账号，没有广告，没有追踪。你的进度留在你的设备上，你也可以随时保存一份备份。

再回来的理由

你的小镇，你的汉字卡，每天一道谜题

你玩的每一局，都会建起一些能留下来的东西。

重建一座驿站小镇

你赢得的每一颗星，都用在东海道上一座古老的驿站小镇上：渡口、旅馆、寺庙学堂、城门，最后是祭典。

收集每一个汉字

每个汉字都是一张卡：遇到时是纸卡，记住后是墨卡，掌握后是金卡。有些金卡会闪光，要等它们变成金卡的那一刻，你才知道是哪几张。

每天一道汉字谜题

每天一个由两个汉字组成的词，按你的 JLPT 级别出题，所有人的都一样。在六次机会内找出它，保持你的连续记录，再分享你的结果。

常见问题

值得了解

需要手写笔吗？

不需要。Learn Kanji 是为手写笔设计的，比如 Surface Pen、iPad 上的 Apple Pencil，或你的设备支持的任何手写笔；但它也能用手指在触摸屏上书写，或者用鼠标。用手写笔时，你可以把手掌放在屏幕上；在 Windows 上，你还可以把笔翻过来擦除，并按住笔的侧边按钮获得提示。

它能在哪些设备上运行？

Windows 10 和 Windows 11 的电脑、平板和二合一设备，通过 Microsoft Store 获取。在 Mac、iPad、Android 平板或手机，或者 Chromebook 上，请在浏览器中使用，并从浏览器的菜单中安装它（在 iPad 上：先点“分享”，再点“添加到主屏幕”）。安装后可离线使用。

必须会平假名和片假名吗？

不用。每个读音也会用罗马音显示，所以你在还不会读假名时就能开始，以后再把罗马音关掉。

可以配合我的班级使用吗？

可以。基础级别和中级级别的课序与 Basic Kanji Book 和 Intermediate Kanji Book 一致。把你的课程级别设为目标，并在班级学到的那一课停下。Learn Kanji 与这些书的出版社没有关联。

取消订阅会怎么样？

完整版会开放到你已付费的期限结束。之后，基础1、你赢得的课和你的进度都会保留。可随时在 account.microsoft.com/services 取消；在浏览器中，则通过 Gumroad 收据里的链接取消。

我的进度是私密的吗？

是的。Learn Kanji 可离线使用，并把你的进度保存在你的设备上。它没有账号，没有广告，也没有追踪。详见隐私政策。

用过 Learn Kanji 的早期网页版吗？

它位于 maximsf08.github.io/learn-kanji，把你的进度保存在你使用它的那个浏览器里。请在同一个浏览器中打开这个地址：它会把你的进度导入到这里，或者保存成备份文件，供 Windows 应用使用。
