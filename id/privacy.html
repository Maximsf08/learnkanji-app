Kebijakan privasi Learn Kanji: Pen-Enabled

Terakhir diperbarui: 2 November 2026

Learn Kanji: Pen-Enabled adalah aplikasi latihan menulis kanji untuk Windows dan untuk browsermu. Aplikasi ini tidak mengumpulkan, menyimpan, mengirim, atau membagikan data pribadi.

  • Tulisan, kemajuan, dan pengaturanmu hanya disimpan di perangkatmu, di folder data milik aplikasi itu sendiri.
  • Aplikasi ini tidak memiliki akun, analitik, iklan, atau pelacakan, dan tidak memerlukan koneksi internet untuk pelajarannya.
  • Dasar 1 tidak perlu dibeli. Jika kamu membeli Learn Kanji Full (langganan atau pembelian sekali bayar), Microsoft Store mengurus pembelian dan perpanjangannya, serta memberi tahu aplikasi paket apa yang dimiliki akun Microsoft-mu dan sampai kapan. Aplikasi tidak menerima rincian pembayaranmu. Kamu mengelola dan membatalkan langganan di akun Microsoft-mu. Pernyataan privasi Microsoft berlaku untuk Microsoft Store: privacy.microsoft.com.
  • Saat kamu mengetuk tombol pengeras suara, Windows membacakan kata itu dengan lantang memakai suara yang terpasang di perangkatmu.
  • Cadangan yang kamu simpan adalah file di perangkatmu sendiri. Aplikasi tidak mengunggahnya.
  • Kode undangan dan kode terima kasih untuk teman dibuat di perangkatmu dari angka acak. Kode itu tidak berisi data pribadi, dan aplikasi tidak pernah mengirimnya ke mana pun: kamu sendiri yang membagikannya jika kamu mau.
  • Untuk pemecahan masalah, aplikasi menyimpan log teknis singkat (pesan saat aplikasi dimulai dan pesan dari Store, tanpa data pribadi) di folder datanya di perangkatmu. Log itu tidak pernah dikirim ke mana pun.

Mencopot pemasangan aplikasi menghapus semua yang disimpannya.

Di browsermu

Edisi web Learn Kanji (learnkanji.app/app) mengikuti aturan yang sama, dengan perbedaan berikut:

  • Tulisan, kemajuan, dan pengaturanmu hanya disimpan di penyimpanan browsermu di perangkatmu. Menghapus data situs, atau menghapus aplikasi yang terpasang, akan menghapus semuanya.
  • Jika kamu membeli Learn Kanji Full di sana, Gumroad mengurus pembayaran, perpanjangan, dan bukti pembayaranmu, dan kebijakan privasi Gumroad berlaku untuk hal itu: gumroad.com/privacy. Aplikasi tidak pernah menerima rincian pembayaranmu.
  • Saat kamu memasukkan kunci lisensi, aplikasi mengirim kunci itu ke layanan lisensi Gumroad untuk diperiksa, dan memeriksanya lagi sesekali selama kamu terhubung ke internet. Hanya kunci dan produk yang terkait dengannya yang dikirim; aplikasi hanya menyimpan paket dan tanggalnya, di perangkatmu.
  • Saat kamu mengetuk tombol pengeras suara, fitur ucapan bawaan perangkatmu membacakan kata itu dengan lantang. Beberapa suara yang disediakan oleh browser atau sistem operasi mungkin memakai layanan online; aplikasi tidak mengendalikan atau menerima data itu.
  • Jika kamu pernah memakai versi web sebelumnya di maximsf08.github.io/learn-kanji, alamat itu dapat membawa kemajuanmu ke edisi web di browser yang sama. Alamat itu meneruskan kemajuan lewat bagian tautan setelah "#", yang tidak dikirim browser ke server mana pun, dan edisi web bertanya dulu sebelum membawanya masuk.
